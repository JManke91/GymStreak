# Domain Docs

Gym Streak is a single-context repository.

## Before exploring

- Read `docs/architecture.md` before structural work; it is the repository's architectural source of truth.
- Read the relevant feature document in `docs/` before broad code exploration.
- If `CONTEXT.md` or `docs/adr/` exists in the future, read the parts relevant to the work. If neither exists, proceed without comment.

## Vocabulary and decisions

Use established Gym Streak terminology in ticket titles, acceptance criteria, and implementation. Surface any conflict with a documented architectural decision rather than silently overriding it.
